# Image Compressor — Free Online Tool

**Image Compressor.** Compress JPG, PNG and WebP images in batch with quality control. Download as ZIP. 100% in your browser. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/image-compressor](https://miguelacm.es/tools/image-compressor)

## ✨ Features

- **🗜️ Batch compression:** Compress many images at once with a quality slider and download them all in a ZIP.
- **🔒 100% private:** Everything runs in your browser with the Canvas API. Your images never leave your device.
- **🔄 Format conversion:** Optionally convert to JPEG, WebP or PNG while compressing.

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/ImageCompressor.git
cd ImageCompressor
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/image-compressor
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/image-compressor
```
